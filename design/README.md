Fonte atual: [Revista Multidisciplinar — Fome](https://www.figma.com/design/5xsYU3wLGps73ZzUHfNhyz/Revista-Multidisciplinar---Fome?node-id=503-352), frame `503:352`, “Revista • leitura contínua (scroll)”. Extração em 27/10/2026.

Primeira extração: [cópia anterior](https://www.figma.com/design/KLDNjVtWNSo9uEGgR2gjcR/Revista-Multidisciplinar---Fome--Copy-?node-id=156-746), seção `156:746`, “Entrega Final”. A extração dessa cópia foi interrompida pelo limite do plano e retomada com o novo arquivo fornecido pelo usuário.

`figma/*.json` e `figma-new/*.json` preservam as respostas originais do contexto de alta fidelidade, incluindo textos, classes de referência, nomes e IDs. Os registros de erro da primeira cópia são históricos. Os URLs temporários desses registros não são usados pelo site nem incluídos em `dist/`.

`source-map.json` identifica as fontes das 22 telas. Sete layouts existentes foram reaproveitados, com os textos conferidos contra a nova fonte e com o componente atualizado dos pensadores. `assets-manifest.json` associa os assets aos nós; arquivos idênticos são compartilhados. `pages-imported.json` registra as páginas geradas. `src/pages/`, `src/figma-components/` e `src/figma.css` contêm a conversão para React e CSS local, sem Tailwind.

`new-inventory.json` registra componentes, variantes e hyperlinks. `new-verified.json` contém as ações e os valores de cada estado interativo. `new-summary-navigation.json` registra todos os destinos atuais do sumário. `all-source-texts.json` preserva os 520 blocos de texto das 22 páginas; `npm run verify:content` compara esses blocos ao HTML renderizado.

O usuário autorizou corrigir os links das páginas 10 e 11 e, depois, as chamadas “pp. 22–23” do editorial, da página 16 e da proposta da página 21 para “p. 22”. As chamadas das páginas 05, 06 e 14 já apontavam para 22 na nova fonte. As respostas brutas do Figma permanecem intactas.

Os números exibidos nos gráficos vieram dessas referências. Nenhum valor ausente foi estimado. A transposição preserva as fontes citadas pela revista; não constitui uma nova verificação acadêmica independente dessas fontes.
